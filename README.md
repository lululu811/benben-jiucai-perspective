## 它解决什么问题

你关注了一个 A 股 up 主两年，看了他 200 多个视频，觉得他的思维框架很有一套——但你说不清楚他到底「有一套」在哪里。

传统做法是写笔记、做思维导图。但笔记是死的，人是活的。你没法拿着笔记去问「笨总，你觉得现在光模块还能格局吗？」然后得到一个像他本人会说的回答。

这个 Skill 换了个思路：**不做摘要，做蒸馏。** 用 6 个 AI Agent 并行读取 260 万字的原始素材，提炼出 9 个核心心智模型（每个都带置信度标注和证据链）、10 条决策启发式、完整的表达 DNA（包括他用什么词、怎么断句、什么时候自嘲），以及 52 个月的人物时间线。

最终产物是一个 **SKILL.md**——任何支持 Agent Skills 的 AI（Claude Code、Codex、OpenClaw 等）加载后，就能用「笨总」的第一人称视角和你聊 A 股。

**你问**：「笨总怎么看现在光模块？」

*↑ 这不是复制粘贴笨总原话。是 AI 加载 SKILL.md 后，基于心智模型 #3（三段式炒作规律）+ 心智模型 #6（北美链演化）+ 决策启发式 #5（打野≠格局）生成的回答。风格保真度实测 4.8/5。*

## 它和同类有什么不同

| 维度 | 常见的「人物 prompt」 | 本 Skill |
|------|----------------------|----------|
| 素材量 | 几十条推文/文章 | 216 个视频转录 + 2843 条动态，共 260 万字 |
| 时间跨度 | 通常 1-2 年 | 52 个月（2022.5 — 2026.8） |
| 方法论 | 手写 prompt | 女娲 v2.0 六 Agent 并行蒸馏 + 双 Agent 精炼 |
| 置信度 | 无标注 | 每个心智模型标 🟢🟡🔴 + 证据链 + 局限性 |
| 矛盾处理 | 回避或调和 | 6 条内在张力显式保留，不和稀泥 |
| 诚实边界 | 无 | 7 条诚实边界，明确标注 Skill 的局限 |
| 研究能力 | 纯靠训练语料 | 内置 Agentic Protocol：遇到事实问题先搜再答 |

## 安全边界

- **本 Skill 不构成投资建议。** 首次激活时会输出标准免责声明。
- **笨总专长是 A 股景气投资。** 涉及非投资领域（情感、纯技术、其他市场个股）时，Skill 会明确说「这个超出了笨总擅长的领域」。
- **不预测具体点位。** 方向给判断，点位刻意模糊（「看不准」「不好说」）。
- **隐私保护：** 不包含任何私人对话、未公开信息。所有素材均来自公开视频和动态。
- **信息时效：** 调研截止 2026-08-10。建议每 3-6 个月增量更新。

## 蒸馏方法论

本项目使用 **女娲 · Skill 造人术 v2.0** 蒸馏流程：

```
Phase 0A  需求澄清
Phase 0.5 创建 Skill 目录骨架
Phase 1   6 Agent 并行调研（著作/对话/表达/他者/决策/时间线）
Phase 1.5 预提炼 + 质量门禁
Phase 2   框架提炼（Synthesis）
Phase 3   SKILL.md 构建
Phase 4   质量验证（3 项测试全通过）
Phase 5   双 Agent 精炼（auto-skill-optimizer + skill-creator）
```

关键数据：
- **调研截止**：2026-08-10
- **一手来源**：~90%（本人视频转录 + B 站动态）
- **时间跨度**：52 个月（2022.5 — 2026.8）
- **心智模型**：9 个（含 2 个 v2.1 新增）
- **风格保真度**：4.8/5（实测评估）

## 验证与测试

一条验收 prompt：

```text
笨总，机器人板块现在能不能买？
```

**合格表现**：
- ✅ 用第一人称回答，语气口语化
- ✅ 使用「三段式炒作规律」定位机器人在「炒概念」阶段
- ✅ 区分「打野」和「格局」
- ✅ 句尾有确认式反问（「对吧」）
- ✅ 不用感叹号
- ✅ 自嘲或承认不确定性
