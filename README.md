## 它解决什么问题

你在 A 股投资时是不是经常：

- 不知道现在该买什么板块，追热点总是被套
- 看不懂景气度周期，买卖时机总是错
- 仓位管理混乱，要么满仓要么空仓
- 想建立景气投资框架，但不知道怎么入手

**这个 Skill 把笨总的景气投资体系变成了可以直接对话的 AI 顾问。**

基于 **216个B站视频AI转录（约260万字，覆盖2024.9-2026.6共22个月）** 的深度蒸馏，提炼出：
- **7个核心心智模型**（流动性驱动、景气度周期、板块轮动...）
- **10条决策启发式**（流动性占绝大因素、景气度优先...）
- **完整的表达DNA**（口语化、确认式反问、不用问号感叹号）

激活后，AI 会**直接以笨总的身份和你对话**——用他的景气投资框架、他的表达方式，帮你分析板块景气度、评估仓位策略。

## 快速开始

### 安装

```bash
# 方式1：使用 skills CLI（推荐）
npx skills add lululu811/benben-jiucai-perspective

# 方式2：手动安装
git clone https://github.com/lululu811/benben-jiucai-perspective.git
cd benben-jiucai-perspective
# 将 SKILL.md 放到你的 Agent 能读取的位置
```

### 装完第一句话

激活后对 Agent 说：

```text
用笨总的视角，帮我分析一下现在哪个板块景气度高？
```

或者：

```text
笨总会怎么看现在的 A 股行情？
```

## 能做什么

| 场景 | 它会交付什么 |
|------|------------|
| **板块景气分析** | 用流动性+景气度框架分析板块投资价值 |
| **仓位策略评估** | 用笨总的仓位管理方法评估你的持仓 |
| **投资逻辑审视** | 用景气投资框架审视你的投资逻辑 |
| **市场周期判断** | 判断当前市场处于什么周期阶段 |
| **学习方法** | 告诉你笨总是怎么研究景气投资的 |

### 核心特点

1. **流动性优先** — 流动性是赚钱的主要因素
2. **景气度驱动** — 买景气度高的板块
3. **口语化表达** — 像聊天一样，确认式反问
4. **能力圈清晰** — 专注 A 股景气投资，不碰别的

## 安全边界

### 这个 Skill 不会做的事

- ❌ **不会给出确定性的买卖指令** — 所有分析仅供参考
- ❌ **不分析美股/港股/加密货币** — 专注 A 股
- ❌ **不会泄露个人隐私** — 所有信息基于公开视频推断
- ❌ **不会硬套框架** — 超出能力圈的问题会直接说"看不准"

### 重要提醒

> **免责声明**：此 Skill 基于公开视频推断，非本人观点。所有输出均不构成投资建议。
