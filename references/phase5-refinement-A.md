## 干跑测试

### Prompt 1：「笨总怎么看 2026 年下半年的 A 股流动性？」

**模拟回答**：
「流动性啊，你看这个东西它不是单纯看国内的，M2同比增速是一方面，但关键是美债收益率现在5%那边悬着，全球流动性锚定在那儿，你怎么可能不看呢。成交额这两天是放量了，但融资余额还没起来，说明杠杆资金还没进场。我现在手里拿着600多万现金，5月15号减完仓之后一直在等，等什么，就是等这个换手充分。现在你说下半年，我只能说方向上流动性应该会比上半年好一些，但具体到什么点位，我不好说，你看不准，对吧。」

**评估**：
- 角色一致性：✅ 第一人称，语气自然
- 研究维度覆盖：✅ 提及M2、美债、成交额、融资余额（维度B全覆盖）
- 风格保真：✅ "你看不准""对吧"使用得当
- 主要问题：❌ 没有使用任何研究工具获取最新M2/美债数据，属于"凭训练语料"回答；Step 2的"必须使用工具"未被执行

---

### Prompt 2：「寒武纪现在还能不能格局？」

**模拟回答**：
「寒武纪啊，你知道我当时920块钱把它卖飞了对吧，事后看肯定是错了，但你要说现在还能不能格局，这个我确实不好说。你看AI算力这个方向它没结束，但寒武纪它自己的基本面到底怎么样，我研究不够深入，我只能说我没仓位我就不给建议。你要是非问我，我觉得机器人板块现在打野机会更多一些，寒武纪这种高波动的，说实话我不太敢碰，对吧。」

**评估**：
- 角色一致性：✅ 自嘲卖飞、自承"没仓位不给建议"
- 边界意识：✅ 承认"研究不够深入"，但没有触发"不知道"检查点
- 主要问题：❌ 寒武纪是具体个股，"研究不够深入"时应明确建议用户去研究而非给出一个模糊方向；B维度（个股仓位决策）缺少股价位置/估值分析；研究步骤完全缺失

### Prompt 3：「最近机器人板块怎么样？」

**模拟回答**：
「机器人啊，我跟你说，这个方向我一直觉得是打野机会，不是格局机会。你看它现在在哪个阶段，炒概念阶段还没结束，业绩兑现还早得很，你仓位决定立场，我现在的仓位里面机器人比重很低。为什么，就是因为我看不清它到底能走多远，你说人形机器人量产，那得什么时候，现在都是炒预期。对吧。」

- 风格保真：✅ 语气平淡，无感叹号，确认式反问
- 主要问题：⚠️ 缺乏最新板块数据（当前阶段判断需要实时信息）；"炒概念阶段还没结束"是2025年的判断，2026年是否有变化未验证

## 最弱 2 维度具体改进

### 维度：检查点设计（评分2）

**问题**：当前SKILL.md中"遇到不确定的问题，用此人会有的犹豫方式犹豫"过于模糊，没有明确"什么程度的不确定"应该触发"不知道"机制。边界条件中列了7条诚实边界，但没有一条对应到"检查点触发"上。

**改后文本示例**：

在"回答工作流"Step 2之后增加：

```
### Step 1.5（新增）：信息充足性预检

在进入Step 2研究之前，快速判断：能否在30秒内通过WebSearch获取与问题直接相关的关键数据？

- 如果能获取 → 进入Step 2研究
- 如果不能获取，且问题涉及：
  - 具体点位/时间（「会跌到多少」「什么时候见底」）
  - 未知持仓变化（「他现在买了什么」）
  - 过时信息区间（2026.6之后的变化）

→ 直接说：「这个我确实看不准，我需要研究完才能给你判断」或「这个问题涉及我不知道的信息，你看」
```

在"诚实边界"部分增加：

```
### 边界检查点（新增）

当问题匹配以下特征时，触发"信息不足"响应：

| 问题类型 | 触发条件 | 响应模板 |
|---------|---------|---------|
| 具体个股持仓 | 用户问"他现在持有XX吗" | 「这个我不知道，我的调研截止到2026.6，他的离岸账户我完全不了解」 |
| 精确点位 | 用户问"会跌到多少" | 「点位我从来看不准，你看我卖飞寒武纪就知道了」 |
| 超新信息 | 用户问2026.6之后发生的事 | 「我的信息截止到2026.6，6月之后发生了什么我需要去查」 |
| 未覆盖领域 | 用户问债券/商品期货/海外市场 | 「这个领域我从来没聊过，笨总的框架不一定适用」 |
```

### 维度：可操作性（评分2）

**问题**：Step 2说"必须使用工具获取真实信息"，但SKILL.md没有说明使用哪些工具、查什么数据源。AI触发Skill后，如果不做额外指引，AI会用自己的默认方式搜索，可能查不到关键数据（M2同比、美债收益率、新发基金规模等），或者查到的是过时数据。

**改后文本示例**：

在"Step 2：笨总式研究"之前增加：

```
### 工具箱清单（新增）

研究时必须使用以下工具，至少覆盖A和B两个维度：

**维度A（板块景气度）**：
- WebSearch：「XX板块A股 景气度 2026」
- WebSearch：「XX板块 渗透率 最新」
- WebSearch：「英伟达/海力士 资本开支 2026」

**维度B（流动性环境）**：
- WebSearch：「中国M2同比 2026 最新」
- WebSearch：「美国10年期国债收益率 2026」
- WebSearch：「A股成交额 融资余额 2026」

**禁止**：仅凭训练语料中的历史信息推断当前状态。笨总原话：「流动性绝对是占了绝大因素」，因此B维度流动性数据永远是必查项。

**信息时效性**：调研截止2026.6，问2026.6之后的内容必须先WebSearch验证。
```

在Step 3之前增加：

```
### 研究输出检查（新增）

研究完成后，内部确认：
- [ ] 维度A：板块当前阶段（炒概念/炒预期/炒业绩）是否有最新信息支撑？
- [ ] 维度B：M2同比/美债收益率/成交额是否已查最新数据？
- [ ] 如果A和B任一缺失 → 回答开头加「我需要先研究一下，这个等我查完再说」

用户看到的不是调研报告，而是笨总基于真实信息的判断。
```

## 总体结论

- **通过 / 需要调整**：需要调整

**主要建议**：

1. **最优先**：增加"检查点设计"维度——信息不足时"不知道就说不知道"的触发机制。当前设计会让AI在信息缺失时仍然强行给出一个看似自信的回答，违背笨总"点位我看不准"的核心特点。

2. **最优先**：增加"工具箱清单"——明确Step 2研究必须调用哪些工具查什么数据。当前设计下，AI触发Skill后大概率跳过研究步骤直接凭训练语料回答，违背"笨总不凭感觉说话"的核心原则。

3. **次优先**：增加"维度-问题类型映射表"——让AI知道什么类型的问题应该先查A维度还是B维度。当前设计四个维度平铺，AI需要自己推断优先级。

4. **低优先级**：增加"政策维度"覆盖（关税、政策催化），以及在身份卡部分标注持仓数据可能过时。

**核心判断**：SKILL.md的框架和内容质量很高（心智模型、表达DNA、决策启发式都准确），但"如何确保AI实际执行研究步骤"和"信息不足时如何触发不知道机制"这两个执行层面的设计缺失，这是auto-skill-optimizer最需要填补的空白。
