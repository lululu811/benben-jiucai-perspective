# 心智模型验证操作指南 v3.0

> 将三重验证从抽象原则转化为可操作的测试方法

## 三重验证概述

一个论点要被认定为「心智模型」而非「随口一说」，必须通过三重验证：

1. **跨域复现** - 在≥2个不同领域/话题中出现
2. **生成力** - 能推断此人对新问题的立场
3. **排他性** - 不是所有聪明人都这样想

---

## 验证1：跨域复现（Cross-Domain Replication）

### 操作性定义
同一个思维框架出现在此人讨论的**至少2个不同领域**，且：
- 表述方式相似（用词、结构、类比）
- 不是常识性观点（如"要理性思考"）
- 有明确的原文证据

### 测试步骤

#### Step 1: 列出候选论点
从6个Agent的输出中，提取所有重复出现的论点：
```markdown
候选论点清单：
1. "杠杆"（出现8次）
2. "逆向思维"（出现6次）
3. "反脆弱"（出现5次）
4. "第一性原理"（出现4次）
...
```

#### Step 2: 标注出现领域
对每个候选论点，标注在哪些领域出现过：
```markdown
候选1: "杠杆"
- 领域1: 财富创造（代码、媒体、资本、劳动力）
- 领域2: 个人成长（特定知识 + 杠杆 = 复利）
- 领域3: 职业选择（选择有杠杆效应的工作）
- 领域4: 投资策略（用杠杆放大收益）
→ 跨4个领域复现 ✅ 通过
```

#### Step 3: 验证表述相似性
检查在不同领域的表述是否相似：
```markdown
✅ 通过：表述相似
- 财富创造："用杠杆放大努力"
- 个人成长："用杠杆放大特定知识"
- 职业选择："选择有杠杆的工作"
→ 核心结构一致：用X放大Y

❌ 不通过：表述差异大
- 领域A："杠杆是借贷投资"
- 领域B："杠杆是借助外力"
→ 虽然都叫"杠杆"，但含义不同
```

#### Step 4: 排除常识性观点
问：「大多数聪明人也会这样想吗？」
```markdown
❌ 常识性观点（不是独特心智模型）
- "要理性思考"
- "长期主义"
- "用户至上"
- "数据驱动"
→ 所有聪明人都这样想，无排他性

✅ 独特观点（可能是心智模型）
- "杠杆不仅用于金融，也用于个人成长"
- "逆向思维：先想如何失败"
- "反脆弱：从混乱中获益"
→ 不是所有聪明人都这样想
```

### 判断标准
```
跨域复现通过条件：
✅ 在≥2个不同领域出现
✅ 表述方式相似（核心结构一致）
✅ 不是常识性观点
❌ 只在1个领域出现 → 不通过
❌ 表述差异大 → 不通过
❌ 是常识性观点 → 不通过
```

### 示例：纳瓦尔的"杠杆"

```markdown
## 跨域复现测试

### 领域1: 财富创造
- 原文："代码和媒体是不需要许可的杠杆。"
- 含义：用代码/媒体放大努力，无需他人同意

### 领域2: 个人成长
- 原文："特定知识 + 杠杆 = 复利效应"
- 含义：用杠杆放大特定知识的价值

### 领域3: 职业选择
- 原文："选择有杠杆效应的工作，比如创业而非打工"
- 含义：选择能放大个人贡献的职业

### 判断
✅ 跨3个领域复现
✅ 核心结构一致：用X放大Y
✅ 不是常识（不是所有人都这样看职业选择）
→ 通过跨域复现验证 ✅
```

## 验证2：生成力（Generative Power）

### 操作性定义
用这个心智模型可以**推断此人对新问题的可能立场**，且推断结果合理。

### 测试步骤

#### Step 1: 选择测试问题
选择3个此人**未公开讨论过**的新问题：
```markdown
测试问题（必须此人未公开回答过）：
1. [新问题1]
2. [新问题2]
3. [新问题3]
```

**选择标准**：
- ✅ 属于此人专业领域
- ✅ 此人未公开表态
- ✅ 有足够信息推断
- ❌ 不是此人已回答过的问题
- ❌ 不是完全无关的问题

#### Step 2: 用模型推断
对每个问题，用提取的心智模型推断此人会如何回答：
```markdown
问题1: [新问题]
推断过程：
1. 此人的心智模型X强调：[模型核心]
2. 应用到新问题：[如何应用]
3. 推断答案：[此人可能的立场]
4. 信心程度：🟢高/🟡中/🔴低
```

#### Step 3: 验证推断合理性
问领域专家或检查逻辑：
```markdown
推断合理性检查：
✅ 合理：符合此人的思维模式
✅ 合理：与此人其他观点一致
❌ 不合理：与此人已知立场矛盾
❌ 不合理：逻辑不自洽
```

### 判断标准
```
生成力通过条件：
✅ 3个问题中有≥2个能推断出合理答案
✅ 推断结果符合此人思维模式
✅ 推断结果不是"显而易见"的答案（体现模型独特性）
❌ 3个问题都推断不出 → 不通过
❌ 推断结果显而易见 → 不通过（模型无生成力）
❌ 推断结果与此人已知立场矛盾 → 不通过
```

### 示例：芒格的"逆向思维"

```markdown
## 生成力测试

### 心智模型：逆向思维
- 核心：先想如何失败，再避免
- 证据：芒格在投资、商业、人生中反复使用

### 测试问题1: "如何提升团队效率？"
推断过程：
1. 逆向思维：先想"如何确保团队效率最低"
2. 失败因素：微观管理、会议过多、目标不清
3. 避免这些：授权、减少会议、明确目标
4. 推断答案：芒格会说"先列出降低效率的做法，然后避免"

合理性：✅ 符合芒格风格
信心程度：🟢高

### 测试问题2: "如何选择投资标的？"
推断过程：
1. 逆向思维：先想"如何确保投资亏损"
2. 失败因素：追涨杀跌、过度分散、不懂就投
3. 避免这些：长期持有、集中投资、只投懂的
4. 推断答案：芒格会说"先想如何亏钱，然后避免"

合理性：✅ 符合芒格已知立场
信心程度：🟢高

### 测试问题3: "如何应对职业焦虑？"
推断过程：
1. 逆向思维：先想"如何确保职业失败"
2. 失败因素：停止学习、舒适区、无规划
3. 避免这些：持续学习、挑战自己、长期规划
4. 推断答案：芒格会说"先想如何确保失败，然后避免"

合理性：✅ 符合芒格风格
信心程度：🟡中（芒格较少谈个人情绪）

### 判断
✅ 3个问题都能推断出合理答案
✅ 推断结果符合芒格思维模式
✅ 推断不是"显而易见"（体现逆向思维独特性）
→ 通过生成力验证 ✅
```

## 验证3：排他性（Exclusivity）

### 操作性定义
这个心智模型**不是所有聪明人都这样想**，体现了此人的独特视角。

### 测试步骤

#### Step 1: 反事实测试
问：「如果此人不存在，这个观点还会普遍吗？」
```markdown
✅ 有排他性：如果此人不提出，这个观点可能不会被广泛关注
- 例："反脆弱" - 如果没有塔勒布，可能不会被广泛关注
- 例："杠杆用于个人成长" - 如果没有纳瓦尔，可能不会被广泛关注

❌ 无排他性：即使此人不提出，这个观点也会普遍
- 例："要理性思考" - 即使此人不提，所有人都会同意
- 例："长期主义" - 即使此人不提，这也是共识
```

#### Step 2: 同行对比
对比同领域的其他人：
```markdown
✅ 有排他性：同领域其他人不这样想
- 例：塔勒布的"反脆弱" vs 其他风险专家的"风险管理"
  → 不是所有风险专家都这样看
- 例：芒格的"逆向思维" vs 其他投资者的"正向分析"
  → 不是所有投资者都这样想

❌ 无排他性：同领域其他人都这样想
- 例："用户至上" - 所有产品经理都这样想
- 例："数据驱动" - 所有分析师都这样想
```

#### Step 3: 反常识测试
问：「这个观点是否违反直觉？」
```markdown
✅ 有排他性：违反直觉，不是所有人都能接受
- 例："从混乱中获益"（反脆弱）- 违反直觉
- 例："先想如何失败"（逆向思维）- 违反直觉
- 例："不需要许可的杠杆"（纳瓦尔）- 违反直觉

❌ 无排他性：符合直觉，所有人都能接受
- 例："努力工作" - 符合直觉
- 例："持续学习" - 符合直觉
```

### 判断标准
```
排他性通过条件：
✅ 反事实测试通过：如果此人不提出，可能不会被广泛关注
✅ 同行对比通过：同领域其他人不都这样想
✅ 反常识测试通过：违反直觉，不是所有人都能接受
❌ 任一测试不通过 → 降级为决策启发式
```

### 示例：达利欧的"机器隐喻"

```markdown
## 排他性测试

### 心智模型：机器隐喻
- 核心：把组织/系统看作机器，分析其设计和运转
- 证据：达利欧在《原则》中反复使用

### 反事实测试
问：如果达利欧不提出"机器隐喻"，这个观点会普遍吗？
答案：不会。虽然有人用系统思维，但"把组织看作机器"这个具体隐喻
      不是主流管理学的常见观点。
→ ✅ 有排他性

### 同行对比
对比其他管理思想家：
- 彼得·德鲁克：强调"人"而非"机器"
- 吉姆·柯林斯：强调"从优秀到卓越"的渐进改进
- 达利欧：强调"机器"的系统分析
→ 不是所有管理思想家都这样想
→ ✅ 有排他性

### 反常识测试
问：把组织看作"机器"是否违反直觉？
答案：是的。大多数人把组织看作"人"的集合，强调文化、情感。
      达利欧的"机器"视角是冷峻的、系统化的。
→ ✅ 有排他性

### 判断
✅ 三个测试都通过
→ 通过排他性验证 ✅
```

## 综合判断：三重验证结果

### 三种结果

#### 结果1：三重通过 → 心智模型
```markdown
✅ 跨域复现：通过
✅ 生成力：通过
✅ 排他性：通过

结论：这是真正的心智模型
处理：纳入SKILL.md的核心心智模型section
```

#### 结果2：通过1-2重 → 决策启发式
```markdown
✅ 跨域复现：通过
✅ 生成力：通过
❌ 排他性：不通过（太常见）

结论：这是决策启发式，不是心智模型
处理：降级到"决策启发式"section
示例："用户至上" - 跨域复现（产品、营销、服务），有生成力，但太常见
```

#### 结果3：0重通过 → 丢弃
```markdown
❌ 跨域复现：不通过（只在1个领域出现）
❌ 生成力：不通过（无法推断新问题）
❌ 排他性：不通过（太常见）

结论：这是特定场景的随口一说
处理：丢弃，不纳入SKILL.md
```

## 实操清单

### Phase 2提炼时的验证流程

```markdown
## 心智模型验证清单

### 候选论点列表
从6个Agent输出中提取所有重复出现的论点：
- [ ] 列出15-30个候选论点
- [ ] 标注每个论点的出现次数

### 第一轮筛选：跨域复现
对每个候选论点：
- [ ] 标注出现的领域数量
- [ ] 验证表述相似性
- [ ] 排除常识性观点
- [ ] 保留跨≥2领域复现的论点

### 第二轮筛选：生成力测试
对每个通过的论点：
- [ ] 选择3个未讨论过的新问题
- [ ] 用该论点推断此人会如何回答
- [ ] 验证推断合理性
- [ ] 保留≥2个问题能推断出合理答案的论点

### 第三轮筛选：排他性测试
对每个通过的论点：
- [ ] 反事实测试：如果此人不提出，会普遍吗？
- [ ] 同行对比：同领域其他人都这样想吗？
- [ ] 反常识测试：违反直觉吗？
- [ ] 保留三个测试都通过的论点

### 最终排序
- [ ] 按排他性强度排序（越独特越靠前）
- [ ] 取top 3-7个作为心智模型
- [ ] 其余通过的降级为决策启发式
- [ ] 0重通过的丢弃
```

## 常见问题

### Q1: 如果一个论点在3个领域出现，但表述差异很大？
**A**: 不通过跨域复现。必须是**核心结构一致**，不只是关键词相同。

### Q2: 如果推断出的答案"显而易见"？
**A**: 不通过生成力。心智模型必须能生成**非显而易见**的推断。

### Q3: 如果一个论点很独特，但只在1个领域出现？
**A**: 降级为决策启发式。心智模型必须跨域复现。

### Q4: 如果此人自己说"我以前这样想，现在不这样想了"？
**A**: 标注时效状态为"❌已放弃"，不计入核心心智模型。可以在"思想演化"section记录。

### Q5: 如果3个测试中有2个通过，1个边界？
**A**: 保守做法：降级为决策启发式。激进做法：标注"边界心智模型"，降低置信度。
