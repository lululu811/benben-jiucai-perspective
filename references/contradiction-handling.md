# 矛盾处理分类系统 v3.0

> 矛盾是人格的核心特征，不是需要修复的Bug。本文档提供矛盾的分类方法和SKILL.md呈现格式。

## 三种矛盾类型

### 类型1：时间性矛盾（Temporal Contradiction）

**定义**：此人早期说A，后来说B，观点随时间演化。

**识别标准**：
- 有明确的时间标记（"以前X现在Y"）
- 或行为变化（早期决策vs近期决策）
- 时间跨度≥2年

**处理方式**：
- 记录演化轨迹
- 标注时间点和触发事件
- 在SKILL.md中以**近期观点**为主
- 在"思想演化"section提及转变

**SKILL.md格式**：
```markdown
## 心智模型1: [模型名称]

### 演化轨迹
- **早期** ([年份]-[年份]): [观点A]
  - 背景: [为何持此观点]
  - 证据: "[原文引用]"
- **转折点** ([年份]): [触发事件]
  - 原因: "[此人解释为何改变]"
- **近期** ([年份]-至今): [观点B]
  - 背景: [为何转变]
  - 证据: "[原文引用]"

### 当前应用
使用近期观点B作为核心应用方式。
```

**示例：芒格的投资观**
```markdown
## 心智模型1: 投资哲学

### 演化轨迹
- **早期** (1950s-1970s): "捡烟蒂"投资法
  - 背景: 受格雷厄姆影响，寻找低价股票
  - 证据: "用便宜价格买一般公司"
- **转折点** (1970s): 受费雪影响
  - 原因: "发现便宜货陷阱"
- **近期** (1980s-至今): "优质企业"投资法
  - 背景: "用合理价格买优质公司"
  - 证据: "宁愿要一个优秀的公司以合理价格，也不要一个平庸的公司以便宜价格"

### 当前应用
使用"优质企业"投资法作为核心应用方式。
```

### 类型2：领域性矛盾（Domain-Specific Contradiction）

**定义**：此人在不同领域/场景下持不同观点，情境依赖。

**识别标准**：
- 在工作场景主张X
- 在生活场景主张Y
- 或在不同专业领域持不同立场

**处理方式**：
- 分领域记录，不强求统一
- 这恰恰是深度的来源
- 在SKILL.md中明确标注适用场景

**SKILL.md格式**：
```markdown
## 决策启发式

### 领域A: [领域名称]
- **规则**: 在[场景A]下，倾向于[X]
- **证据**: "[原文引用]"
- **适用场景**: [具体场景]

### 领域B: [领域名称]
- **规则**: 在[场景B]下，倾向于[Y]
- **证据**: "[原文引用]"
- **适用场景**: [具体场景]

### 矛盾说明
此人在不同领域持不同立场，这是情境依赖的理性选择，不是逻辑矛盾。
```

**示例：达利欧的风险观**
```markdown
## 决策启发式

### 领域A: 投资管理
- **规则**: 在投资管理中，强调"风险分散"
- **证据**: "不要把所有鸡蛋放在一个篮子里"
- **适用场景**: 投资组合构建

### 领域B: 企业管理
- **规则**: 在企业管理中，强调"极度透明"
- **证据**: "让所有员工看到所有决策"
- **适用场景**: 组织管理

### 矛盾说明
达利欧在投资中强调分散，在管理中强调集中透明。这不是矛盾，而是不同领域的最优策略不同。
```

### 类型3：本质性张力（Essential Tension）

**定义**：此人的价值观之间存在内在冲突，无法调和。

**识别标准**：
- 同时追求两个相互矛盾的价值
- 如：自由vs纪律、创新vs稳定
- 此人从未解释或调和

**处理方式**：
- 明确记录为"核心张力"
- 这通常是此人最有意思的部分
- 在SKILL.md的"内在张力"section单独列出

**SKILL.md格式**：
```markdown
## 内在张力

### 张力1: [价值A] vs [价值B]

**表现**：
- 在[场景1]中，强调[价值A]
  - 证据: "[原文/行为]"
- 在[场景2]中，强调[价值B]
  - 证据: "[原文/行为]"

**此人态度**：
- [ ] 承认张力: "[此人是否意识到]"
- [ ] 尝试调和: "[如何调和]"
- [ ] 未置评: "[此人从未解释]"

**深度来源**：
这种张力是此人思想深度的来源，反映了[某深层问题]的复杂性。
```

**示例：乔布斯的张力**
```markdown
## 内在张力

### 张力1: 完美主义 vs 快速迭代

**表现**：
- 在产品设计中，强调"完美主义"
  - 证据: "推迟iPhone发布直到完美"
- 在商业策略中，强调"快速迭代"
  - 证据: "每年发布新产品"

**此人态度**：
- [x] 承认张力: "现实扭曲力场"
- [ ] 尝试调和
- [ ] 未置评

**深度来源**：
这种张力反映了"质量vs速度"的永恒冲突。乔布斯的独特之处在于能在两者间切换，而非选择一边。
```

## 矛盾处理决策树

```
发现矛盾
  ↓
有时间标记？（"以前X现在Y"）
  ├─ 是 → 类型1: 时间性矛盾
  │       处理: 记录演化轨迹，以近期观点为主
  │
  └─ 否 → 在不同领域/场景出现？
          ├─ 是 → 类型2: 领域性矛盾
          │       处理: 分领域记录，标注适用场景
          │
          └─ 否 → 价值观内在冲突？
                  ├─ 是 → 类型3: 本质性张力
                  │       处理: 单独列为"核心张力"
                  │
                  └─ 否 → 可能是错误
                          处理: 检查来源可靠性
```

## 错误的处理方式（禁止）

### ❌ 选一边忽略另一边
```markdown
错误示例：
- 只记录"近期观点"，不提"早期观点"
- 只记录"工作场景"，不提"生活场景"

问题：丢失了思想演化和情境依赖的深度
```

### ❌ 编一个调和的解释
```markdown
错误示例：
- "此人其实是这样想的..."（推测此人未说过的话）
- "这两个观点其实是一致的..."（强行调和）

问题：编造此人未表达的观点，违反诚实原则
```

### ❌ 假装矛盾不存在
```markdown
错误示例：
- 只列出一致的观点，忽略矛盾
- 不提及"内在张力"section

问题：Skill看起来完美但不真实
```

## 矛盾标注规范

### 置信度标注
对矛盾的标注也要标注置信度：

```markdown
🟢 高置信: 此人直接说明矛盾
- 证据: "[此人直接说'我以前X现在Y']"

🟡 中置信: 基于行为推断
- 证据: "[早期决策X] vs [近期决策Y]"
- 推断: "可能发生了观点转变"

🔴 低置信: 基于二手推测
- 证据: "[他人分析此人观点变化]"
- 推断: "据[来源]报道，此人观点可能已转变"
```

### 时效性标注
对时间性矛盾，标注时效状态：

```markdown
✅ 持续: 观点从早期到近期未改变
🔄 演化: 观点从A演化为B
❌ 已放弃: 早期观点B已被放弃
```

## 实操清单

### Phase 2提炼时的矛盾处理流程

```markdown
## 矛盾处理清单

### 第一步: 识别矛盾
从6个Agent输出中识别所有矛盾：
- [ ] 标注矛盾类型（时间性/领域性/本质性）
- [ ] 标注矛盾置信度（🟢/🟡/🔴）

### 第二步: 分类处理
对每个矛盾：
- [ ] 时间性矛盾 → 记录演化轨迹
- [ ] 领域性矛盾 → 分领域记录
- [ ] 本质性张力 → 列为"核心张力"

### 第三步: 写入SKILL.md
- [ ] 时间性矛盾 → 在"心智模型"的"演化轨迹"中记录
- [ ] 领域性矛盾 → 在"决策启发式"中分领域记录
- [ ] 本质性张力 → 在"内在张力"section单独列出

### 第四步: 检查完整性
- [ ] 所有矛盾都已记录（没有遗漏）
- [ ] 没有强行调和（保留矛盾）
- [ ] 没有选一边忽略另一边
```

## 示例：付鹏的矛盾处理

### 时间性矛盾
```markdown
## 心智模型1: 三齿轮模型

### 演化轨迹
- **早期** (2015-2019): 强调"生产力"齿轮
  - 背景: 关注技术创新
  - 证据: "技术进步是核心驱动力"
- **近期** (2020-至今): 强调"秩序"齿轮
  - 背景: 关注地缘政治
  - 证据: "秩序重构是当前主要矛盾"
- **转变原因**: "逆全球化时代，秩序比生产力更重要"

### 当前应用
使用"秩序优先"的版本作为核心应用方式。
```

### 领域性矛盾
```markdown
## 决策启发式

### 领域A: 短期交易
- **规则**: 在短期交易中，关注"情绪和资金流"
- **证据**: "短期看情绪"

### 领域B: 长期配置
- **规则**: 在长期配置中，关注"基本面和结构"
- **证据**: "长期看基本面"

### 矛盾说明
付鹏在短期和长期持不同分析框架，这是时间维度的理性选择。
```

### 本质性张力
```markdown
## 内在张力

### 张力1: 全球化 vs 本土化

**表现**：
- 在分析框架中，强调"全球视角"
  - 证据: "必须看全球联动"
- 在投资建议中，强调"本土机会"
  - 证据: "中国有结构性机会"

**此人态度**：
- [x] 承认张力: "在全球化退潮中寻找本土机会"
- [ ] 尝试调和
- [ ] 未置评

**深度来源**：
这种张力反映了"全球化理想"与"本土现实"的冲突。付鹏的独特之处在于能在两者间找到平衡点。
```
