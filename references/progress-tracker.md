## 自动更新逻辑

在SKILL.md中定义自动更新PROGRESS.md的逻辑：

```python
# 每个Phase完成后，更新PROGRESS.md

def update_progress(skill_dir: Path, phase: str, status: str, notes: str = ""):
    """更新进度追踪"""
    progress_file = skill_dir / "PROGRESS.md"
    
    # 读取现有进度
    content = progress_file.read_text(encoding='utf-8')
    
    # 更新状态
    # ... (简单的字符串替换)
    
    # 写回
    progress_file.write_text(content, encoding='utf-8')
```
